# BridgeDrop downloads

Public installation files and signed update metadata for BridgeDrop.
The application source repository remains private. No GitHub login is required.

Download the Windows installer, Linux AppImage or Android APK from Releases.
Install desktop 0.15.0 / Android 0.8.0 once to enable automatic update checks
and downloads. Existing connections and permissions are retained.

Windows input-service updates require the normal administrator approval.
Android updates require permission to install from BridgeDrop and Android's
installation approval. Linux updates require a writable AppImage.

Release files are verified by SHA-256 and an Ed25519 signed manifest before
in-app installation. This does not replace Windows or Android OS security checks.

Only installers, binaries, notices and update verification data belong here.
Do not upload source code, private keys, tokens, device identities or test data.
